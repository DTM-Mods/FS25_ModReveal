## Description English
```text
Description: Lists every mod and DLC your game is running, with its version, author and file name, and shows what each mod actually has in your savegame. It only reads; it changes nothing in the game.
Hotkeys: Left Alt + I opens the mod list. Controller: none by default, set one for "Mod Reveal: mod list" under Settings > Controls. In the list: Left / Right switch tabs, Up / Down or the mouse wheel select, typing searches, Esc closes; on a controller the stick selects, LB / RB switch tabs, B closes.
GitHub: https://github.com/DTM-Mods/FS25_ModReveal

Tabs:
- Active mods: everything loaded right now, with tags for maps, script mods, mods that don't support multiplayer, unzipped folders and possible duplicates (two mods with the same name).
- DLC: the DLCs in use.
- Not used: mods in your mods folder that this savegame or server doesn't use.
- Changes: what was updated, added or removed since the last time you played this savegame or server. After an update you also get a short message on screen.

In game: how many vehicles, pallets, buildings and hand tools from each mod are in this savegame, and how many are yours. Mods that only add shop items and have nothing in the savegame are tagged NOTHING IN GAME: candidates to remove. Sort by IN GAME to see them first.

Select a mod to see more: mod name, file hash (the one the server compares), what it puts in the shop, scripts, needed mods and the start of its description.

Type to search by name, author, file or version. Click SORT to sort by name, in game, author, file or load order.

On every load the list is written to modSettings/FS25_ModReveal/ModList.txt and ModList.csv, ready to paste into Discord or open in a spreadsheet; SAVE LIST writes them again. Changes.txt lists the changes of the last load for server scripts. On a dedicated server the files and a summary in the server log show what the server runs.

Console: modReveal, modRevealExport, modRevealChanges, modRevealShow (opens the list).

Works in single player and multiplayer.
```

## Before uploading

- The mod has no French: the in-game texts exist in English and German only, and modDesc.xml has only English and
  German descriptions. The French text here does not add translations to the mod.
- It ships console commands (`modReveal`, `modRevealExport`, `modRevealChanges`, `modRevealShow`). Your decision
  whether they stay in a ModHub build.
- It writes files to `modSettings/FS25_ModReveal/` (the mod list, and `Changes.txt` for server scripts). ModHub
  allows modSettings, but say so in the description if GIANTS asks.
- Tested in game as a multiplayer client (list, Changes tab, Left Alt + I). The 1.1.0.1 HUD hiding has not been seen
  in game yet.
- Screenshots: upload the five in [`screenshots/`](screenshots/) (1600x900, unedited in-game shots from `../screenshots/`), in order: 1 a farm with no UI, 2 the Active mods tab, 3 sorted by IN GAME, 4 the DLC tab, 5 the Changes tab. 2-5 show the mod list of a save with many other mods, with their names and authors (also PropaineX / Fennell as authors), and 5 the HUD and Courseplay's bar behind the window.
